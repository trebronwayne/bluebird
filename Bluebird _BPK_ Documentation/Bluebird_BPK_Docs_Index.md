## Reading order

1. **AI Quickstart**: the fastest path from idea to installed app.
2. **Developer Guide**: practical tutorial: manifest, UI, icon, custom installer, testing, release.
3. **Formal Specification**: the rules the installer enforces, plus what is current versus reserved for the future.
4. **Store Specification**: community submission, catalog metadata, hashes, review and updates.

## Current versus future

The formal specification explicitly distinguishes functionality that exists in the current BPS v1 design from
functionality reserved for future Bluebird releases, so developers do not depend on APIs that are not guaranteed.

## In the app
